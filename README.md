## 📌 Deskripsi Project
**Trivia Master AI** adalah aplikasi kuis trivia interaktif modern berbasis web yang menggabungkan kecerdasan buatan dinamis dengan pengalaman pengguna yang imersif dan edukatif. Aplikasi ini dirancang **tanpa memerlukan konfigurasi API Key** dari pengguna akhir, sehingga dapat langsung diakses dengan mulus melalui peramban.

Fitur unggulan dari platform ini adalah fleksibilitas topik yang tak terbatas; pengguna dapat memasukkan topik apa saja secara bebas untuk diracik langsung oleh generator AI secara otomatis, atau memilih dari berbagai kategori siap pakai mulai dari Pengetahuan Nusantara, Sains, Teknologi, Pop Culture, hingga Sejarah Dunia. Setiap soal dilengkapi dengan empat pilihan ganda, pengacak algoritma Fisher-Yates, timer adaptif, serta pelacak kombo streak untuk meningkatkan motivasi bermain.

---

## 🚀 Fitur Unggulan
- ✨ **AI Live Generator**: Membuat soal kuis otomatis secara instan berdasarkan topik bebas yang diketik pengguna tanpa memerlukan API Key.
- 🎯 **Kategori Cepat Populer**: Pilihan kategori instan (🎲 Semua Acak, 🇮🇩 Indonesia & Umum, 💻 Teknologi & AI, 🪐 Sains & Alam, 🎬 Game & Anime, 📜 Sejarah & Budaya).
- 📚 **Master Questions Pool**: Bank soal kaya topik dalam bahasa Indonesia dengan algoritma pengacakan Fisher-Yates.
- 🔊 **Web Audio API Sound Effects**: Efek suara sintetis zero-latency tanpa file eksternal (Harmonic Chime, Thud, Tick, Fanfare) dengan tombol toggle audio.
- ⏱️ **Timer Dinamis & Kustomisasi Soal**: Pilihan mode waktu 15s (Cepat ⚡), 30s (Santai), atau Tanpa Batas waktu; dengan opsi 5, 10, atau 15 butir soal.
- 💡 **Kartu Pembahasan & Edukasi**: Penjelasan fakta ilmiah/historis di setiap soal serta review detail di akhir kuis.
- 🎨 **Modern Glassmorphism UI**: Background animated gradient orbs, frosted glass backdrop, tipografi Outfit modern, dan responsif di semua perangkat.
- 📊 **Statistik & Rekor Lokal**: Pelacak skor tertinggi, jumlah kuis dimainkan, dan akurasi yang tersimpan otomatis via LocalStorage.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik & antarmuka aplikasi.
- **Vanilla CSS3**: Glassmorphism, CSS Grid/Flexbox, Keyframe Animations, Responsive Design.
- **Vanilla JavaScript (ES6+)**: State management, Web Audio API, Fetch API, LocalStorage persistence.
