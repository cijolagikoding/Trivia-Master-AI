# Trivia Master AI 🧠⚡

Platform Kuis Trivia Interaktif Cerdas Berbasis AI Dinamis & Multi-Kategori berbahasa Indonesia.

## 📌 Deskripsi Project
Trivia Master AI adalah aplikasi kuis trivia interaktif modern berbasis web yang menggabungkan kecerdasan buatan dinamis dengan pengalaman pengguna yang imersif dan edukatif. Aplikasi ini dirancang tanpa memerlukan konfigurasi API Key rumit dari pengguna akhir, sehingga dapat langsung diakses dengan mulus melalui peramban.

Fitur unggulan dari platform ini adalah fleksibilitas topik yang tak terbatas; pengguna dapat memasukkan topik apa saja secara bebas untuk diracik langsung oleh generator AI secara otomatis, atau memilih dari puluhan kategori siap pakai mulai dari Pengetahuan Nusantara, Sains, Teknologi, Pop Culture, hingga Sejarah Dunia. Setiap soal dilengkapi dengan empat pilihan ganda, pengacak algoritma Fisher-Yates, timer adaptif, serta pelacak kombo streak untuk meningkatkan motivasi bermain.

## 🚀 Fitur Unggulan
- **AI Live Generator**: Membuat soal otomatis secara instan berdasarkan topik yang diketik pengguna (Tanpa API Key).
- **Master Questions Pool (50+ Soal)**: Bank soal kaya topik dalam bahasa Indonesia dengan algoritma pengacakan Fisher-Yates.
- **Web Audio API Sound Effects**: Efek suara sintetis zero-latency tanpa file eksternal (Harmonic Chime, Thud, Tick, Fanfare).
- **Timer Dinamis & Pilihan Jumlah Soal**: Mode 15s (Cepat), 30s (Santai), atau Tanpa Batas waktu; 5, 10, atau 15 butir soal.
- **Kartu Pembahasan & Penjelasan Edukatif**: Penjelasan fakta ilmiah/historis di setiap soal dan review detail di akhir kuis.
- **Modern Glassmorphism UI**: Background animated gradient orbs, frosted glass backdrop, dan responsif di semua perangkat.
- **Statistik & Rekor Lokal**: Penyimpanan otomatis skor tertinggi dan jumlah kuis via LocalStorage.

## 🛠️ Teknologi yang Digunakan
- **HTML5**: Struktur semantik & antarmuka aplikasi.
- **Vanilla CSS3**: Glassmorphism, CSS Grid/Flexbox, Keyframe Animations.
- **Vanilla JavaScript (ES6+)**: State management, Web Audio API, Fetch API, LocalStorage persistence.

## 💻 Cara Menjalankan
1. Clone repositori ini atau download ZIP.
2. Buka file `index.html` langsung di browser favoritmu (Chrome, Edge, Firefox, Safari).
3. Tidak memerlukan instalasi Node.js, server backend, ataupun build tools.
